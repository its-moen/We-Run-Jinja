JINJA RUN CLUB WEBSITE
======================

Files:
- index.html: complete responsive website (HTML, CSS and JavaScript in one file)
- assets/jinja-bridge-hero.png: generated Jinja Bridge-inspired hero image

Preview:
1. Keep the index.html file in the same folder as the assets folder.
2. Open index.html in a browser.

Publish:
- Upload the contents of this folder to Netlify, GitHub Pages, or your hosting provider.
- If deploying to a static host, ensure the assets folder is uploaded alongside index.html.

Before launch:
- Replace the starter route descriptions/distances with verified safe routes.
- Add actual club meeting days, times and meeting point.
- Connect the interest form to a real form service or backend; it is currently a front-end demo.
- Replace the social placeholder links with the club's real profiles.
